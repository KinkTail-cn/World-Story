# 界面适配与窗口规则

## 操作与适配范围

- F11 或设置中的“全屏视界显示”切换全屏。退出全屏恢复本次进入前的窗口大小、位置或最大化状态；改变音量、抗锯齿等设置不取消最大化。
- F11 在菜单、加载、暂停、背包、蓝图及笔记输入中均有效，每次按下切换一次。设置开关与偏好文件同步；切换保留面板、输入内容和暂停状态，也支持直接运行 Main 场景。
- 普通窗口最小 800×500。已覆盖 800×500、800×600、960×540、960×600、1280×800、1920×1080、2560×1080，以及反复缩小和放大。
- 界面布局使用视口可用尺寸，兼容工程默认的画布缩放和直接使用窗口尺寸的布局。对话框保留边距，缩放后的鼠标坐标仍对应显示的按钮。
- 画布采用等比扩展策略，增加可用宽度或高度以覆盖屏幕，不把画面锁在原来的 16:10 比例内。项目默认设置和运行时应用设置均执行该策略，避免全屏后左右或上下留黑边。

## 各界面行为

| 界面 | 适配处理 |
| --- | --- |
| 主菜单、创建世界 | 按卡片内容和窗口空间居中缩放；出现加载错误时重新核算卡片高度 |
| 设置、加载画面 | 内容卡片随可用空间适配，保存/关闭和进度/提示保持可见 |
| 游戏 HUD | 两侧信息牌不重叠，八格快捷栏和操作提示保留底部边距，长手持名称省略显示 |
| 暂停 | 操作卡片保持居中和边距 |
| 背包 | 保留三栏布局及整体适配，储物/物品库内部滚动，八格快捷栏固定 |
| 蓝图工坊 | 侧栏随窗口适度缩放，右侧属性滚动，保存/制作固定在底部；工具栏与观察控件分开，抽屉折叠后开关仍在屏幕内 |
| 笔记本 | 整张卡片随空间居中缩放，输入、保存、列表和关闭入口保持可见 |
| 功能轮盘 | 窗口缩放后更新中心与半径，确认说明保持在下边界以内 |
| 物品介绍卡片 | 长名称省略显示，卡片随屏幕边缘翻转并约束位置 |
