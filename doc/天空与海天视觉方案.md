# 天空与海天视觉方案

## 视觉方向

以“晴朗海岛午后”为基调。天空高处更蓝，向地平线逐渐变浅；暖白太阳、奶白云顶和浅蓝灰云底与草绿、米棕沙滩协调。保持方块世界的清晰轮廓，并通过云的远近、慢速漂移和少量高层薄云增加空间层次。

| 元素 | 处理 |
| --- | --- |
| 高空与中层 | 从约 `#457DAD` 的高空蓝过渡到 `#7AB3D1` 的浅蓝，避免整片天空被同一层灰雾覆盖 |
| 地平线 | 约 `#C4DBE3` 的柔和雾蓝，衔接远处云与海面 |
| 太阳 | 暖白圆盘、有限范围的柔光晕，视觉方向与实际投影光源一致 |
| 主光与环境光 | 午后约 36° 高度的微暖日光，环境光保留冷色平衡，保持方块与人物的明暗层次 |
| 体积云 | 由正放立方体拼接、合并网格，云顶较暖较亮，云底浅蓝灰；剔除内部面，避免每块一个节点 |
| 云层远近 | 较低云约 58–72 米、较高云约 112–132 米；高度、大小和漂移速度不同 |
| 高层薄云 | 天空材质中的低对比薄纱细节，不使用大量粒子或逐帧重建辐射贴图 |
| 海面 | 保留近处清透与微波，淡化远处重复纹理；海平线用同系雾色平滑衔接，日光反光保持克制 |
| 水下 | 隐藏云网格，天空转为水下蓝；出水后恢复原来的天空、雾色、浓度与云显示 |

## 云层运行规则

- 固定 36 片云，共用 6 种预生成网格；分布由世界种子决定，读档保持同样的布局规律。
- 云沿水平方向缓慢漂移。暂停时停止漂移，恢复游戏后继续。
- 通过 512 米范围的周期分布覆盖远行位置，数量和缓存不随探索距离增加。
- 远云先与同一套天空配色混合，再在不可见处调整周期位置；使用同一个配色函数计算天空与远云，避免透明重影、颗粒淡出或显眼跳变。
- 云没有碰撞、不参与目标拾取、不投下移动的大片地面阴影，也不修改地形与存档数据。
- 玩家相机远裁剪距离为 1400 米，覆盖高层云和远海的雾化范围；地形区块加载仍按原有视距运行。验收相机复用玩家实际的视野、近裁剪和远裁剪参数。

## 实现入口

| 文件 | 职责 |
| --- | --- |
| `scenes/Main.tscn` | 太阳、光照、基础雾与天空资源 |
| `scenes/Player.tscn` | 实际游戏相机的远景覆盖范围 |
| `shaders/coastal_palette.gdshaderinc` | 天空与远云共用渐变、太阳和薄云配色 |
| `shaders/coastal_sky.gdshader` | 天空背景与水下色调 |
| `shaders/clouds.gdshader` | 云的面向着色和远景雾化 |
| `scripts/world/SkyAtmosphere.gd` | 云形、缓存、种子布局、漂移与远行分布 |
| `shaders/water.gdshader` | 近处微波、日光反光、远处细节淡出及海天衔接 |
| `scripts/Main.gd` | 环境实例隔离、云层创建与潜水/出水恢复 |

天空材质没有逐帧时间或相机位置依赖，辐射贴图可缓存；主要动态来自有限数量的云网格位移。水面使用与天空协调的显示配色，并单独处理近处清透和远处雾化，避免重复叠加高光和雾而出现亮带。
