# 随机世界与创造飞行

2026-11-16：创建世界只保留创造和生存两种玩法，两者都生成随机无限地图。

## 创建和探索

- 创建入口不再提供经典岛屿、村庄启程或其他预设地图。世界种子留空随机生成，填写 32 位整数可复现相同世界。
- 新世界从原点到远处全部使用种子地形，不写入固定晴风岛缓存，也不生成初始小屋。村落按区域自然生成，不强制玩家从村落开始。
- 出生点在种子决定的范围内寻找干燥、附近高差较小、头顶有空位的自然地面，避开村落范围和树干树冠；先准备附近区块与碰撞，再交还控制。
- 出生点随世界保存，返回出生点会沿用当前世界的初始位置并检查可站立空间。重新生成世界会保留创造/生存选择，使用新的随机种子。

## 创造模式飞行

| 操作 | 输入 |
| --- | --- |
| 开始 / 结束飞行 | 300 毫秒内双击空格 |
| 水平移动 | WASD，跟随相机水平方向 |
| 上升 | 空格 |
| 下降 | Ctrl 或 C |
| 加速 | Shift |
| 悬停 | 松开移动和升降键 |

单击空格仍然跳跃，按住产生的键盘重复不计作第二次按下。飞行使用原玩家胶囊碰撞，不穿过墙体或屋顶；下降触地后自动恢复步行。生存模式拒绝飞行，暂停和加载期间不处理切换。飞行中人物采用放松的悬浮姿势，披风仍响应实际速度。

保存会记录创造模式的飞行状态；继续游戏先准备保存位置周围的区块，再恢复悬浮。旧存档没有这个字段时按步行恢复，生存存档即使带有飞行标记也不会启用飞行。

## 第三人称握持

普通方块和纸笔都挂在真正的掌心位置。肩肘采用低抬臂、小幅曲肘的携带姿势，物品处于腰侧；方块朝向相对躯干保持端正，纸笔靠近手掌。走跑时保留小幅摆动，挥动时平滑接回动作。

工具、武器保留独立握柄补偿与挥击动作；第一人称相机手持不受第三人称补偿影响。所有物品缩放保持等比。
