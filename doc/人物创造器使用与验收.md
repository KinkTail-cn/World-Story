# 人物创造器使用与验收

首版实现：2026-11-14，Godot 4.7.2，GL Compatibility。

人物创造器用于制作可实际控制的人形模型。它直接开放于创造和生存模式，不消耗背包材料，不设置任务或解锁条件。

## 打开和基本流程

重新运行游戏，加载完成后按 **K**；也可以从暂停菜单打开“人物创造器”。打开后暂停世界，已有草稿在本轮游戏中保留。

1. 先在骨架页调体型，或选择“调骨架”工具拖动关节。
2. 右侧选择附着部位，搭建、选择、移动、染色或删除立方体。
3. 使用动作下拉框查看走跑、跳跃、坐下、游泳和挖掘；切回静止建模继续修改。
4. 填写名称，保存到人物库；点击“应用人物”替换当前玩家，并保存当前世界。
5. 关闭创造器后正常移动、建造和穿戴，F5 随时保存世界。

“保存”保存个人设计，“应用人物”提交到当前世界。两者相互独立：应用后继续编辑草稿，不会自动改变实际玩家；只保存到库也不会替换实际玩家。

## 骨架和体型

运行结构保留原有动作节点名称，增加骨盆、胸部、颈部、左右掌心和脚部，组成 17 个关节。关节关系固定为人形，可调整静止位置和比例。

| 参数 | 范围 |
| --- | --- |
| 基础身高 | 1.1–2.8 米 |
| 躯干、腿长比例 | 0.7–1.4 |
| 手臂长度 | 0.65–1.4 |
| 肩宽 | 0.7–1.5 |
| 胯宽 | 0.75–1.5 |
| 胸腰宽度、身体厚度 | 0.65–1.8 |
| 手臂、腿部粗细 | 0.65–1.6 |
| 头部大小 | 0.7–1.35 |

基础身高用于人体比例，额外方块和发型可能增加最终高度；底部另显示当前模型高度。左右关节默认对称编辑，蓝色手柄表示当前关节，金色手柄表示其他关节。

“调整骨架时重塑身体方块”默认开启。重塑通过体积铺设等边立方体完成，不给关节或网格施加非均匀缩放。关闭后，方块保留自己的尺寸和局部位置，只随骨架移动；改变骨长后可以手工补齐外形。

已编辑的关节偏移随后续比例调整保留；脚部参考点用于维持地面基准。肘、膝、手脚的上下关系和关节范围在提交操作时校验，非法修改作为整次事务撤销。

骨架页顶部的“修复部位连接”用于已有模型：保留手工搭建方块，补齐有对应身体部位支撑的肩颈、髋、肘膝与腕踝连接，并作为一步可撤销操作。新生成模型和开启重塑后的模型自动维护这些连接。

## 方块建模

| 操作 | 输入 |
| --- | --- |
| 放置、选择、染色、删除 | B / V / C / X，或工具下拉框 |
| 单选、多选 | 选择工具点击；Ctrl 点击增减 |
| 框选 | 选择工具在空白处拖动 |
| 移动 | 拖动选中方块；或修改右侧坐标后应用 |
| 复制、删除 | Ctrl+D / Delete，或按钮 |
| 镜像 | 右侧“镜像”，反射位置并交换左右附着部位 |
| 隐藏、锁定 | 右侧按钮；仅辅助编辑，实际人物保留这些方块 |
| 撤销、重做 | Ctrl+Z / Ctrl+Y 或 Ctrl+Shift+Z，最多 64 步 |
| 旋转观察 | 中键，或 Alt+左键 |
| 平移、缩放、聚焦 | Shift+中键 / 滚轮 / F |
| 保存人物库 | Ctrl+S 或“保存” |

每块只有一个边长，范围为 0.005–1 米，提供 0.26、0.13、0.065、0.0325 米预设。单个模型最多 16384 块。不同大小的方块可以贴面搭建，每块仅绑定一个关节。换附着部位保留静止模型上的位置。

改坐标时保留未编辑轴的原始精度；仅改位置不会因为界面显示步长而改变边长。一次拖动、关节移动或批量属性修改只记一笔历史。方块操作保存变动项，骨架整体调整使用压缩快照；骨架、方块和选择状态共同撤销和重做。

生成器使用混合边长的立方体铺设体积，减少薄层和躯干的重合面。不同精度和预算下，自动重塑会有体素近似，精细部位可继续手工调整。

重塑前仅在计算数据中合并相邻、同色、同部位和同编辑状态的体积，再按整体体积铺成立方体，避免逐块预算不足造成躯干空隙。手工挖去的方块不会因为合并而被重新填满，实际显示和保存仍只有独立立方体。

## 功能点、动作和实际玩家

功能点页可调整眼位、呼吸点和右手握持点，绿色标记显示选中的功能点。眼位的三个坐标作用于第一人称镜头，握持点作用于独立的掌心关节；镜头侧向偏移随观察方向转动。

待机和走跑、跳跃、坐下、游泳、挖掘沿用程序动作，按新骨长、躯干转动中心和步幅适配。动作通过关节旋转带动整块立方体，不对单块做混合蒙皮。静止建模和软材质保持固定，动作预览中冻结几何编辑。

实际玩家同步更新：站立/坐姿碰撞体、相机高度、第一人称眼位、手持位置、坐姿偏移、潜水与呼吸点、放置占位和安全返回。移动速度、跳跃能力及 4.8 米采集距离保持原规则。

应用前需要起身并留出足够空间。应用会检查人物数据、地面基准、眼位和碰撞尺寸；过宽、过高、眼位越界或低于地面的身体方块会给出原因。当前位置容不下新身体时，保留旧人物和草稿，可以保存后到开阔处应用。恢复游戏默认人物只替换实际玩家，不删除创造器草稿。

首版是可调的标准人形，不提供任意新增承重肢体或四足动作；不规则身体和极端比例仍可结合穿戴预览手工细调。

## 背包、装备和蓝图

世界玩家、背包和蓝图工坊采用同一份人物定义。原有装备按参考骨架进行适配，结果为独立的显示网格，不改写背包成品的原始设计。

蓝图版本仍为 3，新增可选 `rig_reference`，只存参考体型参数和关节位置。旧图纸缺字段时使用标准人物。打开旧设计时，将编辑副本转换到当前体型，静止拾取、属性、动作预览和制作使用同一参考；保存后该参考随成品保留，换回原人物也可重新适配。

未穿戴的基础装备不做体型重建。仅修改人物方块而骨架未变时，复用已适配装备；适配变换按关节复用，减少编辑与读档的重复工作。

## 保存和兼容

- 人物定义版本为 1，包含稳定 ID、名称、体型参数、关节覆盖、功能点、配色和附着方块。
- `user://characters.json` 保存最多 64 个个人设计；“另存副本”使用新 ID，重复名称可以并存。
- 世界存档 `player.character` 保存完整独立快照，人物库后续变化不会改动当前世界人物。
- 沿用临时文件替换、上一版备份和读档校验；失败保留编辑内容和原内存库。
- 旧世界没有人物字段时，继续使用游戏原人物。缺少可选功能点时补充安全默认值。
- 关闭创造器或在创造器中关闭窗口时，未保存修改提供保存、放弃或继续编辑。保存失败不继续关闭。
- 创造器中按 F5 保存当前世界；人物草稿仍使用保存按钮或 Ctrl+S，界面会明确提示两者区别。

## 建模卡顿优化 · 2026-11-14

首版每次放置或染色会完整校验、复制与压缩约 6200 块数据，重建整个预览网格，并重复刷新列表。拖动时也走同一整模路径，导致明显停顿。

现在编辑预览使用按关节复用的 MultiMesh 实例。放置、移动、染色、隐藏、删除和改挂点只提交变动实例；实例缓冲预留容量，满时按倍数扩展，并恢复既有实例。实际应用到玩家时仍生成独立的合并模型。

方块事务使用稳定 ID 索引和小范围校验，保存和应用继续做完整校验。历史只保留本次方块变化，拖动预览只更新选中项，松开鼠标合成一步历史。体型重塑需要的参考快照延后到真正调整体型时准备；普通编辑无需复制整个身体。列表、拾取候选和包围盒按变动部位更新，光标静止时不重复拾取。

## 部位连接性检查与修复 · 2026-11-15

检查发现，原来只修改骨架坐标和各段体积会产生几类问题：肩宽 1.5 时肩部留下约 0.1575 米空档，头部上移 0.2 米后颈部没有填充，单独移动胸部导致躯干两端偏移；上移膝盖还会带动脚，再被脚底归零抵消。

本次修复：

- 躯干体积由骨盆和颈部两端共同定位，移动胸部转轴不会把整块躯干从骨盆处移开；手工颈部体积同时跟随头部的高度和侧向变化。
- 肩、髋、颈、腕踝使用相邻等边方块连接。肩肘髋膝在相邻刚性部位的实际关节处保留重叠连接，弯曲时仍有共同接触体积；每块仍只随所属关节刚性运动。
- 肩变窄时约束躯干宽度，胯变窄时约束左右腿体积，避免手臂埋进身体或两条腿互相挤压。可见连接采用阶梯方块，不拉伸单块。
- 上移膝盖和骨盆时保持下级脚底的高度，改变实际腿部比例；显式编辑脚部仍允许移动。拖动中的对称和落地预览与提交结果一致。
- 自动连接保存可校验的 `connection` 标记，整体重塑时重新计算，普通搭建、染色和拖动继续走局部更新。旧模型读取时不自动改写，可使用顶部按钮主动修复；移除整条手臂后不会将其重新生成。

关闭“调整骨架时重塑身体方块”时，手工外形仍按原有局部坐标跟随骨架，不会自动补出被拉开的体积；此时可手工搭建，或使用连接修复。连接修复仅处理已存在且有支撑的对应身体部位，不保证任意雕塑都变成连续人体，也不填补手工挖掉的整块身体结构。
