## 一、 核心愿景与设计支柱

> **后续实现更新**：当前已具备 MC 式方块角色、快捷栏同步的双视角手持建材和游泳。水中支持 WASD 游动、空格上浮/跃出水面、C/Ctrl 下潜、Shift 加速、悬停和镜头引导潜泳，可游到岛外远海并返回沙滩。水下具有雾、滤镜和深度提示。海域可探索，陆地方块网格仍为 32×24×32；未生成额外岛屿，也未加入氧气或溺水系统。运行与测试见根目录 `README.md`。

> **2026-09-30 当前工程说明**：本次开始时目录仅保留文档。现已重新建立 `project.godot` 和 `scenes/Main.tscn`，交付创造模式核心切片：32×24×32 岛屿、第三/第一人称跑跳、八种建材、计时拆除、贴面放置、碎屑反馈、快捷栏和暂停。完整现状、运行方式与限制见根目录 `README.md`。第 7.1 节原型表格和旧开发日志为历史记录，不证明本工程已具备背包、存档或移动端系统。

本项目是一款融合**“经典 MC 式自由方块破坏与建造”**与**“清爽日系动漫风格色彩”**的开放世界沙盒冒险游戏。

### 三大核心设计支柱：

1. **坚实纯正的方块沙盒骨架（Solid Cube Sandbox）**：
   * 世界由严丝合缝的标准三维立方体构建；
   * 杜绝任何破面、镂空错位、半透明网格切片；
   * 玩家拥有绝对的自由度，每一块泥土、木材、岩石都能被敲碎开采，并可在任意朝向的表面重新放置搭建。
2. **拒绝像素马赛克，拥抱动漫纯净美学（No Pixel-Art, Pure Anime Aesthetic）**：
   * **彻底告别原版《我的世界》那种 16×16 满身斑驳颗粒噪点的低清贴图**；
   * 采用吉卜力、新海诚式的清爽手绘色调，色彩饱满温润；
   * 表面是干净无噪点的微纹理色块，光影呈现柔和的卡通二分明暗（Toon Shading）。
3. **丝滑舒适的第三人称越肩操作（Silky Third-Person Controls）**：
   * 摆脱传统方块游戏僵硬粗笨的操作手感；
   * 采用日系 RPG 式流畅顺滑的越肩第三人称跑酷，支持自动台阶平滑跨越、优雅跳跃翻越山岭，并可自由无缝切换第一人称精密建造。

### 2.2 卡通着色器 (Toon Shader) 技术参数

* **漫反射二值色阶阶梯 (Diffuse Stepping)**：
  * 明暗交界阈值：`0.55`；
  * 平滑过渡边缘（Feather Width）：`0.08`（既有动漫剪影感，又不至于过度生硬）。
* **暗部阴影色调偏置**：
  * 阴影颜色乘数：`Color(0.72, 0.75, 0.88)`（暗部带一层轻微的日系蓝紫色冷光天光反射，杜绝死黑）。
* **高光模型**：
  * 粗糙度默认锁定在 `0.65`（呈现温润纸质或手办哑光），金属方块锁定在 `0.2` 并启用圆环形动漫高光（Cel Specular）。

## 三、 大世界体素几何与区块参数

### 3.1 几何规格标准
* **标准体素方块尺寸**：精确为 **$1.0\text{m} \times 1.0\text{m} \times 1.0\text{m}$** 的正六面体。
* **单区块规格 (Chunk Size)**：
  * 水平宽度：$16$ 格 ($16\text{m}$)；
  * 水平深度：$16$ 格 ($16\text{m}$)；
  * 垂直高度：$32$ 格 ($32\text{m}$)。
* **单区块体素容量**：$16 \times 32 \times 16 = 8,192$ 方块。
* **内存存储**：连续一维平铺数组 `PackedByteArray`，每方块仅分配 1 字节（8-bit 材质 ID，内存单区块常驻仅 8KB）。

### 3.2 网格烘焙与性能红线
* **面剔除铁律 (Hidden Face Culling)**：
  * 仅为紧邻空气的面生成几何顶点；
  * 严禁渲染内部不可见面，确保单区块面数降低 80% 以上。
* **物理碰撞体生成**：
  * 基于生成的无缝外壳网格自动调用 `create_trimesh_shape()`，确保玩家踩在方块边缘平整稳固，无任何下陷或穿模。

## 四、 主角操控与相机运动学参数

### 4.1 角色运动学参数标准

| 参数名称 | 设定基准值 | 物理含义与手感设计目的 |
| :--- | :---: | :--- |
| **常规走跑速度 (Walk Speed)** | `4.8 m/s` | 轻松自如的基础探索节奏，步行时不拖沓 |
| **疾跑冲刺速度 (Sprint Speed)** | `7.8 m/s` | 按住 Shift 触发，带轻微镜头拉远动感 |
| **起跳初速度 (Jump Velocity)** | `7.0 m/s` | 垂直起跳高度精确为 $1.25\text{m}$，确保能稳健跳上 1 格高的方块 |
| **下落重力加速度 (Gravity)** | `18.0 m/s²` | 略大于现实重力，使下落起跳干脆利落，杜绝水下漂浮感 |
| **自动爬阶高度 (Step-up Height)**| `0.55 m` | **核心舒适度指标**：遇到半砖或 0.5m 台阶无需按跳跃键自动走上 |
| **角色胶囊体碰撞尺寸** | 半径 `0.4m`，总高 `1.8m` | 符合标准人体比例，能在 1 格宽、2 格高的通道中自如通行 |

### 4.2 越肩与第一人称相机参数 (CameraRig)

* **第三人称越肩模式（默认核心视角）**：
  * 弹簧臂基础长度：`3.2 米`；
  * 摄像机水平偏移（右肩机动）：`+0.35 米`；
  * 垂直高度偏移：`+1.4 米`；
  * 默认俯仰视角：`-12°`；
  * 视野角度（FOV）：`70°`；
  * 旋转跟随与插值阻尼：`15.0 * delta`（丝滑跟随无延迟）。
* **第一人称精密建造模式（按 V 键切换）**：
  * 弹簧臂长度：`0.0 米`；
  * 垂直高度：`+1.6 米`（与眼平齐）；
  * 视野角度（FOV）：`80°`；
  * 屏幕正中心显示极简纯白半透明十字准星（`+`）。

## 五、 方块挖掘、放置与交互手感参数

### 5.1 准星射线与选中框标准
* **最大操作交互距离 (Reach Distance)**：精确为 **$4.8\text{米}$**（约 5 个方块身位）。
* **方块选中高亮指示器 (Selection Outline)**：
  * 采用干净纯粹的**黑色/白色手绘细线框**（线宽 `0.02m`）；
  * 在目标方块外沿略微外扩 `0.005m`，消除共面 Z-fighting 闪烁；
  * 严禁使用遮挡视线的肮脏实色遮罩。

### 5.2 挖掘破坏反馈体系
* **连续长按挖掘机制**：
  * 首次点击立即开始蓄力，挖掘耗时：
    * 树叶方块：`0.1 秒`（瞬间击破）
    * 泥土/草块：`0.35 秒`
    * 原木方块：`0.7 秒`
    * 岩石方块：`1.1 秒`
* **方块碎裂粒子特效 (Block Debris Particle)**：
  * 破坏瞬间，原方块位置爆散出 **8 ~ 10 颗微型无噪点小方块（尺寸 0.12m）**；
  * 散落材质颜色与被破坏方块完全一致；
  * 赋予随机向外炸裂初速度（$2.5\text{m/s}$），受重力影响在地面轻微弹跳并于 `0.7 秒` 内缩小淡出；
  * 配合清脆明快的日系击破音效。

### 5.3 紧贴表面放置判定 (Surface Snapping)
* 鼠标右键点击时，获取射线碰撞点所在的法线方向向量（`Normal`，如向上、向左、向前）；
* 新方块放置坐标严格计算为：`新坐标 = 目标方块坐标 + 整数法线向量`；
* 防卡身保护：若新方块的世界包围盒与玩家自身胶囊体发生重叠，禁止放置并弹出轻微提示音，防止玩家被封进墙体内。

## 六、 手机移动端双端操作适配与触控规范

为保障手机移动端（Android / iOS）玩家与 PC 键鼠玩家拥有同样丝滑的操作体验，系统采用**“底层统一输入抽象 + 表现层双端自适应触控层”**的跨平台架构方案。

### 6.1 移动端经典人体工学双拇指触控布局

```
┌────────────────────────────────────────────────────────────────┐
│ [快捷视角 V]                                        [菜单/背包] │
│                                                                │
│                                           (视角滑动旋转区)      │
│                                                                │
│      ┌─────┐                                     ┌───┐         │
│      │ 摇杆 │                                     │挖掘│         │
│      └─────┘                                 ┌───┴───┴───┐     │
│   (左手移动走跑区)                             │放置│跳跃│     │
│                                              └───┬───┬───┘     │
│               [ 1 ][ 2 ][ 3 ][ 4 ][ 5 ][ 6 ]                   │
│                       (底部触控快捷栏)                          │
└────────────────────────────────────────────────────────────────┘
```

#### 1. 左半屏：动态自适应虚拟摇杆 (Dynamic Floating Joystick)
* **交互机制**：
  * 左半屏幕为虚拟摇杆触控感应区，手指在左半屏任意位置按下时，摇杆底座瞬间在该触点生成；
  * **行程与速度映射**：
    * 死区半径：`12 像素`（防止手指微小颤抖误触）；
    * 走步区间：拖拽距离在 `12px ~ 45px` 时，输出线性比例速度（$0.0 \sim 4.8\text{m/s}$）；
    * 疾跑冲刺（免按 Shift）：拖拽距离超过 `45px` 并推至外圈时，**自动无缝激活疾跑冲刺状态（$7.8\text{m/s}$）**，极大降低手机操作疲倦感。
  * 手指离开屏幕时，摇杆自动淡出隐藏。

#### 2. 右半屏：视角拖拽滑动区 (Look & Drag Zone)
* **交互机制**：
  * 右半屏除特定功能按键外的空白区域，均为摄像机旋转滑动区；
  * 手指在区域内滑动，带动第三人称越肩相机的水平（Yaw）与俯仰（Pitch）旋转；
  * **触控灵敏度**：水平滑动 `0.005 弧度/像素`，垂直滑动 `0.0035 弧度/像素`，带有 `12.0 * delta` 平滑阻尼回弹，防止手机划屏眩晕。

#### 3. 右下角：黄金三角动作按键群 (Action Button Cluster)
* **跳跃按键 (Jump Button)**：
  * 位置：右下角核心拇指最易触达位置（外距右边缘 `60dp`，距底边缘 `60dp`）；
  * 尺寸：圆形半透明磨砂质感，半径 `40dp`，图标为向上起跳箭头；
  * 点击时触发跳跃（初速度 $7.0\text{m/s}$）。
* **破坏/挖掘按键 (Mine Button)**：
  * 位置：跳跃键斜上方；
  * 尺寸：圆形半径 `34dp`，图标为动漫小镐头；
  * 长按时持续破坏准星所指方块。
* **放置方块按键 (Place Button)**：
  * 位置：跳跃键斜左方；
  * 尺寸：圆形半径 `34dp`，图标为动漫立方体方块；
  * 点击时在当前准星瞄准的方块朝向法线表面立刻放置手中方块。
* **直接点屏交互双轨支持**：
  * 除了使用独立按键，玩家也可以直接用手指**点触画面中的目标方块**：单点放置方块，长按直接挖掘破坏。

#### 4. 底部大图标触控快捷栏 (Mobile Hotbar)
* 放置于屏幕底部正中央，高度适度放大为 `60dp`；
* 每个方块槽位尺寸为 `52dp × 52dp`，间距 `8dp`；
* 点击对应方块格子即时切换主手手持方块，选中的格子带有高亮金黄边框。

#### 5. 顶部功能小按键
* 右上角提供【视角切换按键（V）】与【工坊/背包按键（B）】，尺寸为 `36dp`，清爽精致无噪点。

### 6.2 双端自适应平台检测与架构

* **无感跨平台输入总线**：
  * 虚拟摇杆与触控按键只负责将触控事件转化为 Godot 原生 `InputEventAction`（如 `move_left`、`jump`、`attack`、`place_block`），向统一事件流发送；
  * 核心游戏逻辑与角色控制器不关心输入来源是 PC 物理键盘鼠标，还是手机触控屏，实现 100% 解耦！
* **UI 自适应显隐**：
  * 游戏启动时检测 `OS.has_feature("mobile")` 或 `DisplayServer.is_touchscreen_available()`；
  * 移动端环境下：自动加载并显示触控 HUD 层；
  * PC 桌面端环境下：默认隐藏触控层，支持按快捷键（如 `F8`）开启触控层模拟调试。
* **异形屏安全区适配 (Safe Area)**：
  * 自动读取设备屏幕安全区，UI 两侧预留最小 `24dp` 安全边距，彻底杜绝手机横屏时刘海屏或打孔摄像头遮挡按钮。

## 七、 全阶段迭代路线图 (Milestones)

### 阶段 1：纯正动漫风方块世界核心切片（当前核心攻坚目标）
* **目标**：打造一块让人一眼就爱上的日系动漫方块测试陆地。
* **交付指标**：
  1. 生成 $32 \times 32$ 精致方块岛屿（包含纯净草地丘陵、岩石地基、2~3 棵日系手绘方块大树）；
  2. 丝滑顺畅的第三人称主角越肩跑跳与镜头控制；
  3. **双端无缝操作支持：PC 键盘鼠标 + 手机端虚拟摇杆与触控动作按键**；
  4. 准星对准方块高亮显示手绘细线框；
  5. 敲碎方块（带小方块碎屑飞溅）与紧贴表面放置方块；
   6. 底部提供动漫风格的方块切换快捷栏。

**家具扩展（ID 6/7）**：木桌高 1 格，矮木桌高 0.5 格，均占用一个水平体素单元，具有桌面、四条桌腿和对应碰撞。岛屿初始各放一张，可在生存模式挖掘拾取；创造模式两款物品位于背包储物区，拖至前五格快捷栏后放置。现阶段均按整格网格对齐，不支持桌面上同一体素单元内叠放其他方块；在矮桌上方放置方块会留出半格空隙。旧存档中的已有体素 ID 不变。

**家具扩展（ID 8/9/10/11）**：长木桌高 1 格、沿 X 轴固定占两格，ID 8 为主格、9 为不可单独放置的续格；任意一格被挖掘时整张移除，只掉落一个 ID 8 物品。木凳子 ID 10 高半格，木椅子 ID 11 总高一格（半格座面加椅背），各占单格。初始岛屿展示各一件，生存模式可采集后放置；创造模式背包储物区提供物品，拖到快捷栏使用。放置长桌时两格必须同时为空且在世界边界内，旧存档 ID 0 至 7 不变。

**坐垫（ID 12）**：坐垫实际厚度为 `0.25` 格，只能放在已有方块上方，支持整格、半格和其他家具支撑面。坐垫占用支撑方块上方的空体素，网格根据下方方块高度自动计算实际 Y 偏移，因此放在半格方块上不会悬空。靠近坐垫按 `F` 可坐下，坐姿高度随下方方块变化；必须先拆除坐垫才能拆掉其支撑。当前不支持同一体素内叠放多个坐垫。

**视觉基准更新（2026-09-30）**：按用户最新要求，采用高清日系动漫风、纯净色块、卡通光照、平滑采样与抗锯齿。旧“动漫像素风”和最近邻低分辨率显示方向停止使用。当前程序化角色与场景为风格原型，正式动漫角色和精美手绘资源尚待制作。

**方块破坏输入规则**：破坏工具默认关闭，PC 端必须先按 `B` 启用，再按住鼠标左键破坏；再次按 `B` 关闭后，左键不会修改地形。HUD 会显示当前破坏工具状态。

### 7.2 当前版本验收口径

每次提交至少完成以下人工流程；自动化测试只证明逻辑和节点契约，不能替代实机操作验收：

1. 从主菜单创建一个生存存档，不点击保存直接返回主菜单，存档列表不应出现该世界。
2. 进入生存世界，挖掘方块，拾取掉落物，放置方块，主动保存，再返回主菜单。
3. 重新载入该存档，确认世界修改、玩家位置和背包数量恢复。
4. 创建创造模式世界，确认五个快捷栏槽位有方块，连续放置不消耗数量，破坏方块不生成冗余掉落物。
5. 使用 `V`/`F5` 和鼠标滚轮切换视角，确认第一人称不显示自身模型，第三人称可正常移动。
6. 打开背包，分别测试点选交换、鼠标拖拽、触屏拖拽和 `ESC` 关闭，确认角色不会移动或误挖。
7. 在桌面端开启触控 HUD，测试摇杆、视角滑动和动作按钮；移动端发布前必须补做真实设备测试。

### 7.3 暂不实现的功能边界

以下内容仍属于阶段 2 至阶段 5 的规划，不得作为当前版本缺陷直接追责，也不得在没有验收指标的情况下提前扩张：多区块异步流式加载、生态群落、工具与工作台合成、生物 AI、近战武器、蓝图建造、水体、云存档、多人联机和远期微体素武器力学系统。

### 7.4 参数偏差登记规则

本文件中的设计参数是目标值，原型代码可能存在为手感测试而调整的运行值。例如当前角色代码使用步速 `5.5 m/s`、冲刺 `8.5 m/s`、重力 `20 m/s²`，而本基准目标为 `4.8 m/s`、`7.8 m/s`、`18 m/s²`。这类差异必须在开发日志中登记，完成手感验证后再决定统一到基准值或修改基准文档，禁止无记录地长期分叉。

### 阶段 2：自然生态与手感深度扩充
* **目标**：让方块大世界具有生命力与探索感。
* **交付指标**：
  1. 方块树木砍伐连锁破坏（砍断底座原木，上方树干与树冠依次自然掉落）；
  2. 敲碎方块生成微型方块掉落物，具有物理浮动与玩家靠近自动磁吸拾取机制；
  3. 引入半透明透亮水体方块与基础日系白云天空盒。

### 阶段 3：工具流转与工作台合成
* **目标**：跑通基础生存工具与建造链条。
* **交付指标**：
  1. 引入木镐、石镐、斧头，不同工具对特定材质产生挖掘加速；
  2. 放置工作台方块，右键交互呼出动漫风合成界面；
  3. 简易建筑蓝图辅助放置。

### 阶段 4：动漫风生物与战斗互动
* **目标**：为方块世界注入生机与危机。
* **交付指标**：
  1. 引入温顺小动物（如日系圆滚滚方块小鸡、小羊）；
  2. 引入夜间巡逻小怪，具备视野感知与追逐攻击状态机；
  3. 挥舞近战武器时产生清爽的动漫半月弧光，命中怪物产生打击顿挫与受击硬直。

### 阶段 5：大世界流式加载与优化
* **目标**：迈向广袤大世界。
* **交付指标**：
  1. 基于 FastNoiseLite 实现多区块（Multi-chunk）流式异步加载与卸载；
  2. 探索不同动漫生态群落（樱花方块林、枫叶红山、白雪皑皑的方块雪山）；
  3. 内存与帧率极限优化，保障 60 FPS 交付。
