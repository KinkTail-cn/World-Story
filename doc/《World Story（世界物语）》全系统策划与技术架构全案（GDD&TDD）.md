一、 项目概述与核心愿景

1.1 项目定位

本项目是一款融合“微观体素物理装配”、“跨时代文明地缘争霸”与“全视角平滑协同”的开放世界沙盒 RPG。系统彻底摒弃传统沙盒“搜集材料合成死板属性装备”的数值体系，依托严谨的连续介质力学与离散几何算法，建立一套自微观构件到宏观战局完全自洽的涌现式体验。

1.2 四大核心设计支柱

物理几何自下而上赋能 (Bottom-Up Physics Empowerment)装备没有硬编码词条。一把冷兵器、抛射物或机械的伤害形态、挥砍惯性、穿透压强、飞行轨迹与折断耐久，完全由玩家在网格内拼装的几何形态与体素材料的物理常数实时测算决定。

全视角无缝协同机制 (Seamless Tri-Perspective Synergy)打破传统单一视角限制，有机融合第一人称（沉浸战斗/微观拼装）、第三人称（旷野跑酷/自制装配审视）与上帝视角（RTS 领地规划/军团编队/批量建造）。

物理自知与地缘涌现的 AI-NPC (Physics-Aware Cognitive Agents)NPC 搭载本地端侧大语言模型（SLM）与目标导向行动计划（GOAP）。NPC 不仅能读懂玩家自制武器的力学缺陷并做出性格化吐槽，还能依据领地资源盈亏与文明代差，自主发起巡逻、建设、劫掠与逆向工程。

微缩实感体素美术 (Tactile Diorama Voxel)放弃低清马赛克像素贴图，采用纯色调色板、次世代 PBR 材质微表面、着色器边缘假倒角（Bevel Shader）与移轴景深，营造出宛如真实手工玩具沙盘般的厚重质感。

七、 微缩实感体素美术规范

1. 材质与着色器（Stylized PBR）

杜绝 16×16 像素马赛克，采用调色板贴图结合物理材质通道：

金属类（高碳钢、黄铜）：金属度 ，粗糙度 。着色器强制开启边缘假倒角（Procedural Edge Bevel），在方块交界处烘托真实切削高光。

石材与陶土类：金属度 ，粗糙度 。附加细微程序化法线微噪点，表现凿打痕迹。

2. 视角自适应环境后期 (Adaptive Post-Processing)

第一人称 (FP)：FOV 设为 。景深聚焦近景，强化局部点光源高动态光照（HDR），营造压迫感。

第三人称 (TP)：FOV 设为 。开启体积雾（Volumetric Fog）与林间丁达尔光，表现旷野生存的广袤。

上帝视角 (RTS)：FOV 压平至 。动态激活移轴景深（Tilt-Shift Effect）（上下边缘高斯虚化），强化 SSAO 阴影，呈现治愈系玩具微缩模型质感。

3. 物理破坏视觉语言

八、 底层性能优化与算力调度方案

8.1 宏观体素存储与网格构建优化

数据存储极致压缩 (Bit-Packing)： 单 Chunk 规格为  体素。严禁使用字典或 Godot 原生 Object 存储。采用底层连续 PackedByteArray，每个体素仅分配 16 位（2 字节）：

Bit 0 ~ 7 (8-bit)：材质类型 ID（支持 256 种物理材质）。

Bit 8 ~ 11 (4-bit)：体素损伤阶段度量。

Bit 12 ~ 15 (4-bit)：功能状态掩码（连接态、通电态、可燃标志）。单 Chunk 内存仅占用 。对未开采地下或全空气 Chunk 实施 RLE 行程编码，内存压缩比超 。

多线程贪婪面合并 (C++ GDExtension Greedy Meshing)： 网格生成由 C++ 编写并通过 WorkerThreadPool 分发。仅为暴露于空气的面生成网格，并将同材质共面四边形贪婪合并为单个大 Quad 面。单 Chunk 渲染顶点数降低 ，以单条 ArrayMesh 统一提交 GPU。

8.2 物理引擎瘦身与刚体降级 (Godot-Jolt)

自制武器凸分解 (Convex Decomposition)： 微观拼装完成后，严禁使用活动凹面网格（Concave Trimesh）参与动态物理。后台自动运行快速凸包分解（V-HACD），将其转化为顶点数不超过 16 ~ 32 的单一凸包或复合盒体（Compound BoxShape3D）。

睡眠唤醒节流： 所有动态生成的体素刚体碎片设置高线速度与角速度阻尼。位移低于  持续  立即强制调用 set_freeze_enabled(true)，剔除物理活跃列表。

8.3 端侧大模型与 GOAP 算力分流

单例串行限流队列 (Inference Queue)： 同一物理帧内严禁并发调用本地模型。建立优先级队列，按“对话中焦点 NPC > 警戒中守卫 > 背景闲聊 NPC”排序。Prompt 强制截断在 300 Tokens 内，输出锁定在 60 Tokens 内，结合结构化 JSON Grammar 消除语法幻觉。

GOAP 时分复用 (Time-sliced Planning)： 领地内数十个 NPC 禁止同帧执行 A* 状态图推演。每物理帧轮询至多 2 个 NPC 重新规划，其余单位仅严格步进执行已缓存的行动队列。

8.4 视角自适应渲染开销抑制

上帝视角 (RTS) 特化：

拉升至高空时，动态将 SDFGI（全局光照）级数自 8 级下调为 4 级，大幅收缩动态级联阴影距离。

距离相机大于  的 NPC，关停 Skeleton3D 骨骼变换计算，切换为顶点动画贴图（VAT, Vertex Animation Texture），由 GPU 顶点着色器驱动位移，确保同屏 500+ 单位稳定 60 FPS。

动作模式 (FP/TP) 特化： 关闭远景 Chunk 网格更新，视野锁定为角色周边  Chunk 的高精加载。武器假倒角 Shader 仅在主角主手激活。

8.5 运行期零垃圾回收分配 (Zero-Allocation)

参数复用：_physics_process 中使用的射线参数（PhysicsRayQueryParameters3D）与 AABB 变量采用模块级全局单例，杜绝帧循环内高频 new()。

对象池化 (Object Pooling)： 自制箭矢、抛射体与体素碎片预先在场景树实例化 300 个节点对象池。生命周期结束时隐藏并重置坐标，杜绝频繁 instantiate() 与 queue_free() 导致的 GC 顿挫。
