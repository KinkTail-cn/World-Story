# 蓝图装备建模需求与实施方案

版本：1.0，2026-11-02。适用工程：World Story，Godot 4.7.2，GL Compatibility。

## 1. 目标与交付边界

玩家可以在游戏内载入林地游侠、曙光骑士、星辉法师的官方设计，选择部件、调整尺寸/角度/颜色/身体挂点，保存个人副本，按材料制作后穿戴。图纸、物品图标、角色穿戴和存档恢复共用同一份模型定义。

本次覆盖七个装备槽的造型制作。工具、武器、摆件继续允许编辑设计；其自定义攻击、伤害、交互物理不属于本次交付。布料沿用现有风动方式，不增加完整软体模拟。地形方块使用原有世界网格。

## 2. 用户操作约定

以“先选工具，再操作画布；选中后右侧编辑参数”为主，常用功能同时有可见按钮和快捷键。

| 操作 | 默认交互 | 约束 |
| --- | --- | --- |
| 放置 | B 工具，左键点击目标表面 | 预览与实际落点/形状/朝向一致 |
| 选择 | V 工具，左键点部件；Ctrl 点击增减选择 | 空白点击取消选择；隐藏部件不参与画布拾取 |
| 框选 | 选择工具拖动矩形 | 按屏幕投影中心选择当前类别的可见、未锁定部件 |
| 换色/材料 | C 工具点击，或对选中部件应用当前材料及颜色 | 染色独立于材料，染色不改变用料 |
| 删除 | X 工具、Delete，或右键点击部件 | 锁定部件不会被删除 |
| 观察旋转 | 中键拖动、Alt+左键拖动，或旋转球 | 普通左键拖动不旋转镜头、不误放置 |
| 平移观察 | Shift+中键拖动 | 只平移观察焦点 |
| 缩放 | 滚轮 | 在允许范围内连续缩放 |
| 复制 | Ctrl+D 或复制按钮 | 复制当前选择并选中新副本，位置错开一个细网格 |
| 撤销/重做 | Ctrl+Z、Ctrl+Y、Ctrl+Shift+Z，及按钮 | 一次放置、批量变换、镜像、清空各算一步 |
| 保存 | Ctrl+S 或保存按钮 | 官方模板载入为独立设计，保存不修改官方源数据 |
| 移动/旋转 | 选中后拖动、编辑栏 XYZ，或方向键/PageUp/PageDown 微移 | 旋转按钮默认 15° 步进，允许精确数字输入 |
| 聚焦 | F 或聚焦按钮 | 聚焦所选部件；没有选择时聚焦当前设计 |
| 退出 | Esc | 先取消正在拖动/选择的操作，再关闭工坊；未保存改动需提示 |

输入框、颜色选择器和弹出菜单获得焦点时，字母和数字交给控件。快捷键不触发游戏背包、坐下、建造等操作。预览动作播放时暂停几何编辑，停止后恢复静止建模姿态。

## 3. 功能拆分、要求和验收

### BP-01 版本化蓝图数据与旧图纸兼容

- 蓝图增加 `schema_version=2`，保留旧 `voxels/cells/part/pos/center/mat/size` 字段的读取。
- 新部件包含稳定 ID、名称、装备类别、形状、三轴尺寸、身体挂点、挂点局部位置/旋转、颜色和表面类型；布料有独立参数。
- 未提供新字段的历史体素继续按原 0.13m 坐标单位及四档尺寸恢复，不改变历史物品外观与成本。
- 拒绝非法形状、未知挂点、非有限数、非正尺寸和超出组件数量上限的数据；失败加载保留当前设计。
- 验收：旧图纸、新图纸、制作后的设计快照均可 JSON 往返，修改设计不改变已经制作的成品。

### BP-02 几何形状、尺寸与斜向旋转

- 支持长方体、楔形块、四棱锥和布料片。立方体是三轴尺寸相同的长方体。
- 新建默认使用当前尺寸预设；XYZ 尺寸可独立输入，用于薄片、皮带、护甲和装饰。
- 支持 XYZ 旋转，旋转按钮默认 15° 步进，可选 45°、90° 和 0.1°；数字输入可精确调整，未修改参数不会被步进控件取整。
- 允许单块、批量移动与绕选择中心旋转。挂点切换应保持部件在静止人物上的位置。
- 验收：45°长条、任意角楔形、尖帽能通过编辑器创建、拾取、删除和再次编辑；旋转保持体积不变。

### BP-03 真实表面吸附与一致的拾取

- 渲染网格与凸体拾取使用相同尺寸和变换。楔形按其真实斜面拾取。
- 贴面放置使用命中点和实际法线，通过新形状在该法线上的支撑距离求中心位置，不把斜面法线取整成世界轴。
- 网格吸附只改变切向位置，随后重新投影到命中平面，避免吸附后悬空/钻入。
- 保留现有轴对齐方块的大小混合铺设行为；画布预览和点击共用落点计算。
- 验收：旋转方块的六个面、楔形斜面及不同大小的新块均贴合；预览中心与实际中心误差不大于 0.001m。

### BP-04 身体部件绑定与镜像

- 可明确选择头、躯干、左右大臂/前臂、大腿/小腿挂点；“自动”用于兼容原有位置推断。
- 盔甲可包含胸甲、独立护肩和袖口；裤甲、长袍可包含分别跟随左右腿的片段。
- 镜像以人物中轴为基准，同时镜像位置、朝向并交换左右挂点；保留材料、染色、形状和布料参数。
- 重复镜像不追加重合副本；锁定部件不被变换。
- 验收：手套、肩甲、护腿在奔跑、坐下和挥击时跟随正确身体部位；镜像两次得到原来的几何。

### BP-05 选择、部件列表与编辑器历史

- 画布单选/Ctrl 多选/框选；列表多选与画布高亮同步。
- 支持命名、隐藏、锁定、复制、删除、移动、旋转和尺寸调整。
- 隐藏是编辑辅助状态，制作时仍保留该部件；锁定只限制编辑，不取消穿戴。
- 历史至少保留 64 步，批量操作是一个事务；新修改清空重做分支。
- 清空只影响当前装备类别，可撤销。载入/新建设计重置历史和选择，取消上一设计的拖拽状态。
- 验收：放置→旋转→镜像→删除→连续撤销/重做后，模型数量、变换和挂点恢复一致。

### BP-06 材料、染色与布料

- 继续使用原有八种物料及其世界资源映射，颜色选择独立保存；提供实体、金属、皮革、布料的外观表面选项。
- 表面类型是外观设置，数值属性不在本次结算范围。
- 布料支持宽/长/固定点、下摆扩宽或收窄、底色、饰边色、无图案/叶形/十字/星纹、风力比例。
- 布料默认顶部固定；预览、图标、穿戴复用同一网格和着色器参数。
- 成本按实际几何体积计算：长方体完整体积、楔形一半、四棱锥三分之一；旋转与染色不改变体积。布料保留可核算的厚度。
- 验收：红/蓝同材质部件用料相同；楔形、锥体成本按体积折算，每种材料最后向上取整；生存制作失败不扣料。

### BP-07 官方可编辑套装模板

- 提供三套七个部位共 21 个官方模板；选择模板后复制到当前编辑设计，并提示可另存副本。
- 当前套装模型转为相同版本的蓝图定义，部件名称、形状、旋转、挂点和披风参数都可由编辑器表达。
- 原物品 ID 与已有配方保持有效；原套装物品通过统一蓝图渲染器显示。
- 官方定义只读，个人修改只写入蓝图库或实体图纸，不回写官方模板。
- 验收：修改游侠斜皮带、骑士肩甲或法师尖帽后，保存、制作、穿戴与读档效果一致。

### BP-08 动作预览、界面和退出行为

- 工坊提供静止、奔跑、坐下、游泳、挥击预览；人物其他已穿装备保持显示。奔跑预览用于检查步态中的关节挂接。
- 左侧为设计来源、装备类别和部件列表；右侧按创建/编辑/布料分组，滚动区域不遮挡画布常用工具。
- 主要操作有按钮提示和选中状态，显示当前工具、选择数量、尺寸与用料。
- 1280×800 与较小窗口完成同一流程，输入不被游戏热键抢走。
- 未保存改动退出时提供保存/放弃/取消，保存失败保持编辑窗口及设计。

### BP-09 渲染成本与持久化

- 制作后的刚性几何按挂点、材料/颜色分组，合并多个相同材质部件的网格；拾取碰撞仅编辑时存在。
- 单份设计最多 4096 个部件；历史采用有上限的快照。
- 图标、穿戴、编辑预览共用几何工具，避免独立模型定义漂移。
- 保存沿用现有原子替换和备份恢复机制，新字段纳入存档校验。

## 4. 技术实施拆分

| 单元 | 职责 | 依赖 |
| --- | --- | --- |
| `BlueprintData.gd` v2 | 序列化、ID、新字段校验、旧字段兼容 | 无场景依赖 |
| `BlueprintGeometry.gd` | 形状、尺寸、坐标变换、镜像、凸体、贴面支撑计算 | 身体静止挂点表 |
| `BlueprintEditSession.gd` | 选择、历史和批量编辑事务 | 数据和几何 |
| `BlueprintPresets.gd` | 三套官方定义转为可编辑蓝图 | 原套装造型定义 |
| `BlueprintEquipmentVisual.gd` | 共用渲染、按挂点合并网格、布料 | 数据和几何 |
| 工坊工具/属性面板 | 用户输入、创建/选中属性、部件列表和动作 | 编辑会话 |
| 制作与存档 | 实体体积成本、成品快照、兼容校验 | 数据和几何 |

优先顺序：先备份当前游戏 → 完成文档 → 数据和几何 → 编辑事务 → 界面接入 → 模板/制作/穿戴 → 自动化及实机验收 → 更新文档和备份。

## 8. 最终验收记录

- 环境：Windows，Godot `4.7.2.stable.steam.ed1daf0bf`；实际窗口使用 OpenGL Compatibility，检查 1280×800 及 960×600。
- 工程导入检查通过；`& .\tests\RunTests.ps1` 自动发现并运行 30 套测试，30 通过、0 失败。
- 建模数据/几何专项：181 项检查通过。编辑器输入/小窗口/保存退出专项：32 项检查通过。实际游戏制作、穿戴及存档恢复专项：24 项检查通过。
- 编辑器专项另在实际 OpenGL 窗口通过 32 项检查，输出官方设计副本编辑、斜面贴合、布料动作和小窗口截图；没有以无窗口结果代替实机画面检查。
- 回归日志只有两个存档保护测试主动制造的备份目标写入错误，无脚本错误或资源泄漏警告。
- 成品合并验证：100 个同挂点、同材料的刚性部件合并为 1 个网格；编辑拾取体不进入穿戴模型；反复切换设计和动作后拾取体数量不增长。
- JSON 变换值使用微米/微度级稳定表示；只改角度或染色不会改变未编辑的尺寸和挂点位置。失败保存回滚蓝图库条目，放弃修改恢复初始载入/上次保存的设计。
