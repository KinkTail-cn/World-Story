# 蓝图装备建模需求与实施方案

版本：2.0，2026-11-04。适用工程：World Story，Godot 4.7.2，GL Compatibility。

## 1. 造型规则

所有物品只用正放立方体拼接。每块长、宽、高相等，允许大小不同；轮廓、细条、薄片、帽顶、纹章和饰边都由多个立方体组成。工坊只有一个边长输入，不提供单轴拉伸、部件旋转、楔形、锥体和自由布料片。

人物挂点随正常关节动作运动，观察相机和整个手持物品沿原动作轨迹运动。造型部件相对自身挂点保持轴对齐，披风没有顶点弯曲或风动形变。

玩家可以载入三套官方装备的 21 个蓝图副本，选择方块、修改边长/位置/颜色/身体挂点，保存、制作、穿戴并读档恢复。工具、武器、纸笔及基础装备也采用立方体拼接显示。自定义工具/武器的功能制作仍属后续阶段。

## 2. 操作约定

| 操作 | 默认交互 | 约束 |
| --- | --- | --- |
| 放置 | B 工具，左键点击表面 | 预览与点击共用计算，只放置正放立方体 |
| 大小 | 四档预设或右侧“立方体边长” | 长、宽、高一起改变 |
| 选择 | V 工具，左键；Ctrl 点击增减 | 空白点击清空选择 |
| 框选 | 选择工具拖动空白区域 | 排除隐藏或锁定方块 |
| 移动 | 拖动选择、位置 XYZ、方向键/PageUp/PageDown | 位置可逐轴输入，不改变方块朝向 |
| 换色/材料 | C 工具，或应用属性 | 染色不改变物料与成本 |
| 删除 | X、Delete、右键或按钮 | 锁定方块不能删除 |
| 镜像/复制 | 左右镜像、Ctrl+D | 镜像位置并交换左右挂点，保持立方体正放 |
| 观察 | 中键/Alt+左键、Shift+中键、滚轮、F | 旋转观察、平移、缩放、聚焦 |
| 撤销/重做 | Ctrl+Z、Ctrl+Y、Ctrl+Shift+Z | 一次批量操作算一步，最多 64 步 |
| 保存 | Ctrl+S 或保存按钮 | 官方设计载入为个人副本 |
| 退出 | Esc | 先取消拖动/选择，再提示处理未保存修改 |

输入控件保留文字和数字编辑；动作预览时暂停几何编辑。右侧分为“方块”和“变换”两页，后者只提供位置。

## 3. 要求与验收

### BP-01 版本化数据与旧图纸迁移

- 新蓝图使用 `schema_version=3`，保留稳定 ID、名称、类别、材料、边长、挂点、局部位置、颜色、表面和编辑状态。
- 历史立方体保留原四档尺寸和 0.13 米坐标单位；旧 v1/v2 的长方体、旋转块、楔形、锥体和布料，读取时采样为立方体拼接。
- 迁移保留材料、染色、挂点、隐藏和锁定；旧披风图案/饰边转成彩色方块。没有显式染色时继续使用物料颜色。
- 转换仅对旧版本执行。新版非法形状、不等边、旋转及布料形变参数均被拒绝。
- 蓝图库、背包中的图纸/成品、已穿戴成品、世界实体图纸均执行迁移，之后使用相同的版本 3 数据。
- 转换是体素近似，细节误差受单块边长影响；数量接近上限时自动降低精度，保证单图不超过 4096 块且保留每个旧部件的表达。重复保存载入不继续细分。

### BP-02 正放立方体与统一边长

- 每个可编辑部件满足 X=Y=Z，相对挂点的基底为单位矩阵。
- 新建、属性应用、镜像、复制、撤销重做、制作与恢复都受同一规则约束。
- 0.26、0.13、0.065、0.0325 米四档预设保留；单边可精确输入 0.005 至 4 米。
- 原斜皮带、羽饰、翼饰和尖帽轮廓通过阶梯拼接表达；细条不能通过拉伸单块生成。

### BP-03 六面拾取与贴面放置

- 每块使用同边长的 `BoxMesh` 与 `BoxShape3D`。
- 六个轴向面支持混合大小贴面；自定义边长通过支撑距离计算落点。
- 画布悬浮预览与点击放置的中心、尺寸及朝向一致，不能重新引入朝表面旋转。

### BP-04 身体绑定与镜像

- 可选择头、躯干、左右大臂/前臂、大腿/小腿挂点。
- 更换挂点保持静止人物上的位置；只改位置某一轴时保留其余轴与边长的精确值。
- 镜像沿人物中轴反射位置、交换左右挂点，保留材料、颜色、边长；重复镜像不追加重合副本。
- 穿戴件随对应关节运动，子方块本身不附加建模旋转。

### BP-05 编辑事务与历史

- 保留单选、Ctrl 多选、框选、列表同步、命名、隐藏、锁定、复制、删除和移动。
- 隐藏和锁定是编辑辅助，制作仍保留方块。
- 历史上限 64 步；清空只影响当前类别且可撤销；非法拉伸/旋转作为整体失败事务，不改变设计或历史。

### BP-06 材料、颜色与披风

- 八种物料及资源映射保留；实体、金属、皮革、布料是外观表面设置。
- 成本按所有立方体的边长三次方累加，每种材料最后向上取整。染色与表面不改变成本，生存制作失败不扣料。
- 披风使用刚性立方体组成的薄层，纹章和饰边使用不同颜色方块；预览和穿戴不使用布料形变着色器。

### BP-07 官方模型与设计副本

- 三套各七个部位的 21 个模板全部由立方体组成；旧 ID、配方和混搭规则保持有效。
- 官方模型输出、个人蓝图、物品图标和角色穿戴共用方块生成/显示管线。
- 官方模板只读，个人编辑写入副本；制作成品保留独立设计快照。

### BP-08 界面、预览与退出

- 单边长输入替代三轴尺寸；移除形状选择、部件旋转、绕挂点旋转、表面朝向及布料形变参数。
- 保留静止、奔跑、坐下、游泳、挥击预览；预览中所有造型方块保持刚性。
- 在 1280×800、960×600 下提供相同操作，保存/制作入口可见。
- 未保存退出提供保存/放弃/取消；保存失败保持设计和窗口，放弃恢复最后保存或初始载入状态。

### BP-09 渲染成本与持久化

- 官方模板最多约 1024 块；用户设计/迁移单图最多 4096 块，生成器在采样前限制候选数量。
- 穿戴成品按挂点、物料、颜色和表面合并网格，保留每个立方体的顶点；不把连续小块替换为长方体。
- 工具、武器、基础装备和纸笔使用共用 `CubeParts.gd` 生成立方体网格，避免增加每块一个场景节点。
- 拾取碰撞只用于编辑；保存继续使用原子替换和上一版备份。

## 4. 实施入口与验证

| 单元 | 入口 | 验证 |

| 立方体生成 | `CubeParts.gd`、`BlueprintGeometry.gd` | 等边顶点、无局部旋转、采样预算 |
| 数据与迁移 | `BlueprintData.gd`、`BlueprintMigration.gd`、`SaveSystem.gd`、`DocumentItem.gd` | v1/v2 迁移、v3 拒绝非法数据、稳定 JSON、成品读档 |

| 生命周期 | 制作、背包、实体图纸和存档 | 编辑→保存→制作→穿戴→F5→读档 |
