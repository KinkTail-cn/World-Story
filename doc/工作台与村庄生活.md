# 工作台与村庄生活

工作台、工具和生活物品蓝图，以及自然村落的基础生活功能。创建世界仍只有创造和生存，两种玩法均使用随机地形，村落自然生成，不增加固定开局或剧情任务。

## 工作台

工作台方块（20）可以在背包中用原木、木板合成；创造模式也可直接领取。另有可放置、可用蓝图自定义外观的蓝图工作台（509）。瞄准工作台按 R 或右键，选择蓝图设计或基础配方合成。

1. 在蓝图工坊选择“工具”“武器”或“物品与设施”。
2. 在新增的“制作”下拉框中选择具体成品，例如铁镐、储物箱或种植箱。
3. 可以载入基础造型，或用正放立方体搭建自己的外观，继续使用选择、染色、镜像、复制和撤销等操作。
4. 保存设计，按“制作入包”。装备在背包中穿戴；工具、武器和设施放入快捷栏使用。

成品保存独立蓝图，后续编辑设计不会修改已制作的物品。物品功能由所选类别决定：工具使用对应木/石/铁级的挖掘效率，储物箱提供储物，熔炉提供加工等。所有造型仍由等边、正放立方体组成。

生存模式支付完整的体积材料与功能材料，例如铁工具需要铁锭、提灯需要玻璃与燃料。材料不足或背包容量不足时不扣除资源。创造模式免费制作。

## 设施操作

| 设施 | 功能 |
| --- | --- |
| 储物箱 / 木桶 | 分别 24 / 12 格，选择背包物品存入或选择容器物品取出；自定义工具、装备和独立图纸会完整保留 |
| 熔炉 | 加入原料与燃料，按游戏时间加工；支持铁矿→铁锭、金矿→金锭、沙子→玻璃、原木→木炭、小麦→面包 |
| 种植箱 | 消耗种子播种，生长后收获 3 份小麦与 2 份种子；未成熟可以清理并取回一份种子 |
| 井台 | 用空木桶换取水桶 |
| 木床 | 恢复生命和空气，并检查床边可站立的地面，将其设为返回位置 |
| 木椅 | 坐下休息，F、移动或空格起身 |
| 提灯 | 开关实际暖色光源，位置与开关状态保存 |
| 蓝图工作台 | 打开设计制作和基础合成界面 |
| 双扇木门 | 两格宽、三格高，按 R 或右键直接开关；门框固定，两扇门向屋内转开，关门时有实体阻挡 |

放置设施需要足够大的平整地面和空位，朝向随放置视角确定。设施使用其实际立方体模型的碰撞；支撑地面和已有设施占用空间受到保护。拆除容器或熔炉前需要取出内容，种植箱中的作物需要先收获或清理；已燃烧的燃料余量不会作为原燃料退回。

容器支持整格存取和普通材料的合并堆叠。创造模式的无限堆叠存入时生成一格 64 份；有蓝图或独立内容的成品始终保留自己的身份。

熔炉最多保留 64 份待加工原料、128 次燃料余量和 8 格成品。煤和木炭可加工 8 次，原木 2 次，木板和木棍 1 次；加工耗时为 5–10 秒。成品空间不足时停止提交下一份结果，等待取出，不覆盖物品。原料顺序和已开始的任务随世界保存。

## 种植与食物循环

树叶整理种子 → 制作种植箱并播种 → 在井台取水、浇灌 → 成熟收获 → 熔炉烘烤 → 食用或交易。

未浇水的小麦约 180 秒成熟，浇水后约 90 秒；中途浇水保持当前生长进度并加快剩余生长。收获产生可继续播种的种子。面包恢复 28 点生命，苹果恢复 12 点；放入快捷栏右键食用，或在背包中右键食物。生命已满时不消耗食物。

## 造型、动画与操作反馈

设施、背包图标和手持共用细化的立方体结构，木板、金属、石材、织物、玻璃、水面、土壤和谷粒有各自的材质表现。结构仍由等边、正放立方体组成；箱盖和摇柄作为完整组件转动，不单独拉伸结构方块。

| 对象 | 造型与实际效果 |
| --- | --- |
| 储物箱 | 空心木板箱、脚、金属箍、锁扣与铰链；打开存储页时掀盖，退出后合盖，内容有箱内示意 |
| 木桶 | 阶梯圆形桶身、金属桶箍和提手盖；使用时提起桶盖 |
| 熔炉 | 石砌炉身、炉膛开口、炉栅、炭块与烟囱；实际加工时显示动态火焰、火星、暖色照明和循环火声，停炉后烟逐渐散去 |
| 木床 / 木椅 | 床头床脚、枕头被褥，椅腿横撑、靠背和椅垫；休息时被褥轻微回落，坐下时椅垫下沉 |
| 提灯 | 金属底座、框架提环、透明灯罩与灯芯；开关同步控制灯芯和照明，手持时同样提供暖光，灯罩可被交互射线瞄准 |
| 种植箱 | 木框、角柱、钉件与凹凸土面；幼苗、长叶和成熟麦穗分阶段显示，播种渐显，浇水有水滴和湿土变化，收获移除实际作物 |
| 井台 | 空心石井圈、水面、木屋顶、横轴摇柄、吊绳和井桶；取水时摇柄转动、井桶下降再提起，绳长跟随，水面微动并有溅水声 |
| 蓝图工作台 | 木桌、抽屉、网格图纸、台钳与锤子；使用时抽屉打开，进入设计或完成制作时有轻微工具动作 |
| 材料、种子与食物 | 木棍束、阶梯金属锭、露出谷粒的种子袋、捆扎麦穗、带切口的面包、果梗叶片苹果、带灰痕的木炭；空桶和水桶区分内腔与水面 |
| 手持与食用 | 水桶水面微动；食用有第一/第三人称抬手、小碎屑和独立声音，最后一份食物在扣除后继续显示至动作完成，切换快捷格可结束显示 |

箱盖具有与可动模型同步的碰撞，受人物、墙体或其他物体阻挡时暂停移动，空间清空后继续；储物操作本身仍检查资源和容量。只有成功操作才触发播种、浇水、收获等反馈。关闭或切换设施菜单会及时结束交互，隐藏的实况预览停止处理和渲染，不重复播放世界音效。

设施菜单右侧显示当前对象的实况：开盖、炉火、作物阶段与灯光都跟随真实记录。窄预览按宽度适配，避免长页面把模型侧面裁掉；正式暂停时，世界动画、预览与生产时间一起冻结。

蓝图属性增加“部件”和“材质”：载入基础造型后可以选中盖子、摇柄、井桶、水面、灯芯、土壤、椅垫或抽屉等分组编辑。新增方块继承当前设置，复制、撤销、重做和 JSON 保存保留设置。没有这些字段的旧蓝图仍可读取，旧容器按顶部位置识别盖子；明确指定的固定主体不会被自动改组。玻璃保留实体碰撞，水面与发光芯不生成额外实体阻挡。

自定义种植箱根据土壤位置安放作物，并预留生长高度；换阶段时不继承临时生长缩放，避免麦苗被重复放大。开盖角度、火焰、烟和水滴等瞬时状态不修改成品蓝图，读档按已保存的开关、任务与作物记录恢复。

渲染按颜色、材质和动画分组合并网格，模型缓存上限 64；火焰、烟、火星和水滴使用固定数量的立方体实例。材质变化按设施实例隔离，关闭一盏灯不会改变另一盏灯。空间音效随设施节点释放，食用声音复用原有六个普通音源。

## 自然村落

- 所有完整正门和庭院附屋门洞会生成双扇木门；已封堵或改造的门口不会覆盖。原有村庄重进后同样检查补齐。门可用木板、木棍、铁锭合成，也可选择蓝图物品类别制作自定义外观。
- 住宅在合适空位配置床与椅子，部分房屋有灯；作坊配置工作台、熔炉和储物箱，仓房配置箱柜和木桶。
- 公共区域有井台和八个种植箱，原来的菜圃造景升级为可以收获、再种植的设施。
- 每村有农夫、铁匠、行商和仓房管理员四类村民，沿村路活动；交互时停下并面向玩家，提供相应材料交易。
- 每项交易有 8 次独立库存，约 300 秒游戏时间后补货；交易要检查材料和背包容量，失败不会扣款或消耗库存。
- 村民目前提供活动与交易，农业和冶炼由玩家操作。村民会避开已被挖空的下一步路面，并在受阻时返回；这不是战斗或剧情系统。
- 村民沿路线经过门时会自动开门，通过后尝试关闭；门口仍有人时等待。玩家开关门不弹出设施菜单、不暂停游戏，长按右键不会反复翻转。开关前检查整个门扇经过的范围，保留门口及内侧开门空间。

进入已有村落时也会在空位补齐设施，完整检查支撑和占用，不覆盖玩家已经改造的建筑位置。离开区域后释放设施与村民节点，默认造景可按种子重建，已经修改过的状态单独保留。

## 时间、保存与界面

设施菜单会锁定玩家移动，生产和其他村民继续活动；正式暂停、加载、蓝图编辑及原有背包界面遵循暂停规则。离开区块后，已开始的生产与种植会按游戏内时间续算，关闭游戏不会按现实时间偷偷推进。

F5、自动保存、返回标题和退出保存均包含：容器内容、成品蓝图、加工原料及顺序、燃料余量、任务进度、作物、灯光和门的开关、床设置的返回点，以及村民位置、行动进度和交易库存。拆掉的生成门保留拆除记录，重载不会再生成一份。保存失败会在当前设施界面明确显示。

新增状态经过校验，原存档不含设施字段时按空状态兼容。旧岛屿、旧村落和全域随机世界沿用各自地形版本。玩家自行放置或回收的设施有稳定编号，不会在区块重载时重新生成一份。
