# 软材质与飘动规则

当前内容：20 种方块、8 种工坊物料、三套装备、基础装备与纸笔。软硬程度和是否适合随风摆动分别判断；动画仅改变显示，逻辑方块、碰撞、材料成本与保存的几何不随动画变化。

## 已接入的效果

| 对象 | 现实特性 | 游戏中的处理 |
| --- | --- | --- |
| 树叶（4） | 叶片柔韧，树枝固定 | 树冠轻摆，紧贴树干的叶块固定；整块位移，幅度约几厘米 |
| 草方块（1）的草叶 | 草叶柔软，下面的泥土稳定 | 裸露草面上稀疏生成短草叶并轻摆；土块和草坪表面固定 |
| 披风（106/406/416/426、自制） | 下摆自由、领口固定 | 继续使用披风的连续后扬、波浪与回卷 |
| 法师袍摆和垂带（423/427） | 上端缝合、下端柔软 | 顶部固定，袍摆和饰边一同轻摆；贴身上衣、帽体、晶饰固定 |
| 游侠羽饰、骑士盔缨（401/411） | 根部固定、上端柔韧 | 根部固定，上端轻摆；兜帽主体、金属翼饰和盔壳固定 |
| 游侠腰间皮袋（407） | 皮革有韧性，摆幅比布小 | 袋口固定，袋身轻微摆动；环腰带与扣件固定 |
| 世界中的单张图纸（109） | 薄纸有弹性，可被笔压住 | 被笔压住的一侧固定，其余纸面和印刷线条一起微动；笔保持固定 |
| 笔记本（108） | 纸页被装订、封面有支撑 | 合上的笔记本固定 |

草叶是少量视觉细节，约每 12 个裸露草方块选一个位置，按区块合并为单个网格。它不占背包物品 ID，也不产生碰撞或拾取目标；遮住草面或挖掉草块后随区块重建更新。

## 保持稳定的物料

| 方块 / 工坊物料 | 原因 |
| --- | --- |
| 泥土（2）、沙子（6）、雪块（18） | 松软、松散或可压缩，并不具有布料式的弯曲结构；不让整块地面飘动 |
| 原木（3）、木板（7）、工作台（20） | 木材结构相对刚硬，工具、木制结构与家具保持稳定 |
| 岩石、鹅卵石、石砖、砂岩、花岗岩（5/13/14/15/17） | 坚硬固体 |
| 矿石、金属、陶瓦、玻璃、黑曜石（8–12/16/19） | 刚性或脆性材质；金的可锻性、云母的层状结构不等于会随风摆动 |
| 八种工坊物料 | 实际对应石头、玻璃、金矿、原木、黑曜石、生铁矿、陶瓦、砂岩；默认都按固定结构处理 |

工坊的“金属 / 皮革 / 布料”是表面外观。新加的“飘动”属性独立表达部件的使用方式，避免只换一个颜色或表面就让整个护甲运动。

## 蓝图操作与兼容

- 在“方块”属性页选择“固定 / 布料轻摆 / 皮革轻摆 / 羽饰轻摆 / 纸张微动”，应用到选中的方块，或用于新放置的方块。
- 飘动在穿戴和动作预览中生效。蓝图静止建模中，当前设计和人物其他已有软材质都固定；物品图标与手持纸笔也保持固定。
- 布料、皮革上端固定，羽饰下端固定；官方饰边和对应主体共用一组位移，保持图案整体一致。
- 每个小立方体的顶点共享同一位移，不拉伸、不旋转单块。金属与固定方块不参与软材质动画。
- 版本 3 保留兼容，新增可选字段 `motion`、`motion_group`；旧图纸没有字段时按原有固定行为恢复，披风仍按类别使用原动画。设置支持撤销重做，并随蓝图与制作成品保存。
