# 界面视觉与操作验收

2026-11-16：面向桌面玩家统一游戏从进入到游玩的界面表现。

## 视觉规则

- 使用海岸配色：海蓝 `#142b34`、青色 `#277e83`、暖白 `#f5f3ec`，黄铜色 `#dfbd7d` 用于当前选择和少量强调。
- 标题、模式创建、设置、暂停、笔记采用清楚的文字层级；背包与工坊使用深色工作面，减少物品和模型周围的杂色。取消厚棕金描边、夸张光晕和装饰表情。
- 共用 8–16 像素圆角、细边线、留白和按钮状态。主要操作为青色，次级操作保持中性，重新生成使用红色边线；键盘焦点有独立可见描边。
- 字体优先使用系统 Microsoft YaHei UI / Microsoft YaHei，并为其他系统指定 Noto Sans CJK SC 和 sans-serif 回退。普通文本约 14–16 像素，标题 22–34 像素，主菜单标题 64 像素。
- `UIStyle.gd` 提供共享主题、输入控件、滑块、选项菜单、物品提示和确认弹窗；图标由矢量路径生成。

## 逐页行为

| 界面 | 当前表现 |
| --- | --- |
| 主菜单 | 默认晴风岛的真实地形、水面与天空，缓慢运镜；左侧品牌与开始操作。有存档时突出继续游戏，否则突出创建世界。错误在当前页面可读显示。 |
| 创建世界 | 模式和世界类型各有独立标题与说明；选择时说明同步变化。创建为主要操作；背景菜单不参与键盘焦点切换，Esc 返回。 |
| 加载 | 深蓝全屏、简短阶段说明、细进度条、数字进度和一条有效操作提示；完成后淡出，保留原有碰撞就绪与输入保护。 |
| 设置 | 声音/操作、显示/画质分组；音量百分比、灵敏度倍数即时更新；全屏与 MSAA 可直接识别，保存失败有独立状态文字。 |
| HUD | 按用户截图反馈移除两角信息牌、准星说明、手持说明、底部操作提示和普通浮动消息。游玩画面使用准星与八格快捷栏；生存状态为快捷栏上方的生命/空气图标条，创造模式不显示状态条。打开模态界面时收起 HUD。 |
| 暂停 | 继续游戏为全宽主按钮；保存、设置、返回出生点、返回标题、重新生成和退出按两列排列，保留保存失败提示。 |
| 背包/合成 | 装备预览、储物与物品库/合成台保持三栏；标题、容量、物品详情、反馈有明确层级。统一格子状态、搜索、分类、配方和领取操作。 |
| 工坊 | 与背包一致的深色工作面；设计库、部件列表、属性和物料分区，当前工具、尺寸与物料用强调色标识。属性滚动时保存与制作固定可见，折叠开关保留在窗口内。 |
| 笔记 | 左侧笔记列表、右侧编辑区；空列表有说明，长内容以首行摘要显示，完整内容可载入编辑。小窗口调整实际列宽和高度。 |
| 功能轮盘 | 深蓝扇区与清晰的动作图标，当前动作和悬停动作可区分；取消、确认提示保持可见。 |
| 物品提示 | 名称与分类分行，属性、描述和操作提示分组；长名称省略，靠近屏幕边缘时翻转位置。 |
| 确认弹窗 | 新建覆盖、重新生成、未保存蓝图使用统一暖白面板与主要/取消按钮。 |

保存失败会写入当前菜单状态；在普通游玩中发生时进入暂停页显示错误，保留原有世界和操作进度。模态关闭按钮只取消当前询问，不会触发保存、覆盖或放弃蓝图。

## 性能与窗口

画布和默认窗口为 1280×800，保持等比扩展。验证了 800×500、800×600、960×540、960×600、1280×800、1920×1080、2560×1080 及反复缩放；保留 F11 全局切换和最大化状态。

主菜单预览使用独立世界，只生成默认有限岛屿，不读取世界存档。菜单隐藏时停用其处理和渲染；工坊隐藏时停止预览渲染，快捷栏物品图标只在可见时更新。
